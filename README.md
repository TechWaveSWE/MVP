## Esecuzione dell'estensione

Requisiti:

- Node.js
- TypeScript compiler (tsc)
- Visual Studio Code

### Passaggi - Esecuzione in modalità sviluppo

1. Clonare questa repo localmente ed entrare nella cartella
2. Eseguire il seguente comando

   ```bash
   npm install
   ```

3. Premere F5 o andare sulla sezione "Run and Debug" ed eseguire la task "Run Extension"
